# World Sensor Card

![To boldly go...](item:ocr_extra_drivers:worldsensorcard)

The world sensor card allows reading of atmospheric information as well as gravity on different planets added by space mods. This can be useful for [robots](../../block/robot.md) or [drones](../../item/drone.md) operating in space.

Supported space mods:
- Ad Astra
- Stellaris
