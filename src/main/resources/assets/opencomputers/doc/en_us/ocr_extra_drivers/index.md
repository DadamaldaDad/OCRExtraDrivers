# OCR Extra Drivers
OCR Extra Drivers is a mod adding compatibility with other mods to OpenComputers Rebooted.

## Table of Contents

### Items
- [World Sensor Card](item/worldsensorcard.md)
- [Satellite Card](item/satellitecard.md)

## Other content

### Changes
- The [Solar Generator Upgrade](../item/solargeneratorupgrade.md)'s power generation now depends on the planet when Ad Astra is installed.

### Drivers
Blocks from the following mods can now be interacted with using an [Adapter](../block/adapter.md):
- Ad Astra
- Immersive Engineering (unfinished)
- Stellaris
